# HR Analytics Dashboard

A sample HR dashboard built with Streamlit, Pandas, and Plotly. Includes fictional employee data and filters for department, status, and gender.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud
Upload `app.py`, `hr_data.csv`, and `requirements.txt` to a GitHub repository.
Use branch `main` and main file path `app.py`.
